# Política de seguridad

No publiques vulnerabilidades, credenciales, datos personales ni documentos de
clientes en issues públicos.

Reporta vulnerabilidades mediante **Report a vulnerability** en la pestaña
Security del repositorio principal:

<https://github.com/TheAlexBig/doc-central-app/security/advisories/new>

Incluye una descripción reproducible, el impacto observado y la versión o URL
afectada. Evita adjuntar información real de clientes.
